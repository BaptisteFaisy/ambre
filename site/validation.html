What “every cut” actually means

One 30-second scenario produces 5 803 disk operations. Its whole reachable state space is 64 591 states — the campaign sums 18 scenarios (different seeds, durations, crash instants and Δv) to reach the one million the specification asks for at “complet” level.

Two expectations are deliberately relaxed — and why

Volatile cache (I7). If the SEAL record was written but never flushed, a disk with a volatile cache may legitimately lose it. The event then comes back with “complete file = no”, which is correct: the seal never became durable. Expecting “yes” there would be demanding a guarantee the hardware does not give.

Flipped bit (I2, I4, I5, I6). A media bit error inside an acquired event destroys data the journal has no redundancy for. What is required of it — and checked — is detection and isolation: the corrupt block is discarded, the neighbours are unaffected, recovery still terminates (I1) and still invents nothing (I3). Claiming the data survived would be a lie.

Latency: what is measured, and one requirement that fails

200 triggers per load, four loads, backend posix: a regular file as the partition, fdatasync() as the flush. The software share is measured with the journal on tmpfs, where the flush has no device to talk to — that separates our code from the media.

Overshoots against the limits: PERF-01 4 / 8 / 1 / 4 of 25–26 crash triggers; PERF-02 0 / 1 / 1 / 1 of 200; PERF-03 0 / 1 / 1 / 0 of 200. The decomposition is the point: at the median the software is 10 µs and the media 3 469 µs — 99.7 % of the freeze is fdatasync() on a file, not our code. On a QNX target with a real partition that media term changes completely, which is exactly why PERF-02 is not claimed here.

PERF-05 — FAILED. Requirement: a producer sends one frame in under 50 µs at p99. Measured: p50 under 50 µs, but the p99 ceiling is ~1 ms with no load and ~5 ms under disk and memory pressure.

Two measured causes, not guesses: (1) the figure is a round trip that waits for the acknowledgement, and the acknowledgement is synchronous; (2) 34–102 GAP records are written on the input path, and a GAP is forwarded synchronously, so it blocks the producer's send. Fix path: acknowledge before journaling, and move GAP emission off the input path. Published as a failure because hiding it would invalidate every other number on this page.

Two independent implementations agreeing byte for byte

The trigger decides whether a crash happened; a wrong threshold means a missing event. Requirement DEC-12 demands a second, independent implementation giving the same decisions.

The contract that makes this possible is arithmetic, not stylistic: integer division truncating toward zero (Python's // floors toward −∞ and would diverge on every negative Δv), fixed units (µs, mm/s², mm/s), and thresholds derived once as mkmh × 5 ÷ 18 → 2 222 / 6 944 / 222 mm/s.

What is not measured

The SDP 8.0 was installed on the development machine on 2026-11-12: the five processes now cross-compile with the real qcc and boot in a QNX 8.0 image under QEMU, and one end-to-end power cut is demonstrated — see the target demo. The live figures of the running target are published on the emulator page — measured inside the guest, not copied from here. What remains below is what the target run did not yet cover: the kernel trace, the security-policy enforcement by the kernel, the latencies measured as a campaign on the target, and the real hardware.
